# PHOTO SEQUENCE 24

Autor: Mariano De Laurentiis. [Sitio oficial](https://marianodelaurentiisfoto.com.ar).

## Windows Studio 3.5.2 Beta - 13/10/2026

Stop motion, Imagen IA y Video IA en una pantalla en castellano e inglés. Estilos Fooocus y personalizados, audio de música y narración, subtítulos SRT, proyectos y exportación MP4 H.264/AAC. Las 277 referencias incluidas funcionan offline. Una imagen sola se guarda sin FPS como JPG/JPEG/PNG; RAW copia el original. Ambos motores ofrecen Sin motor. Narración / voces da acceso a voces Windows, ElevenLabs y Microsoft en línea con cuenta y cuota F0 limitada. La ayuda API enlaza tutoriales oficiales.

Corrección de cuentas/API: editar una cuenta con la clave vacía conserva la anterior; una cuenta nueva requiere una clave. «Comprobar conexión (sin generar)» consulta el modelo sin crear imágenes y no comprueba saldo ni permisos de generación. «Aplicar y generar…» continúa a la confirmación de envío. Los errores incluyen el detalle del proveedor con la clave ocultada. Gemini propone gemini-3.1-flash-image. Manuales ES/EN actualizados, 16 páginas.

El portable se ejecuta sin instalar. El instalador crea acceso y registro de desinstalación. Requiere Windows de 64 bits y Microsoft Edge WebView2 Runtime; FFmpeg/FFprobe incluidos. El idioma se cambia arriba a la derecha de la aplicación.

Verificado en Windows 11: 107 pruebas Python, 97 comprobaciones WebView2, ambos EXE, exportación MP4 con audio/subtítulos y ciclo de instalación/desinstalación/reinstalación. La IA se probó con respuestas simuladas; acceso, cuotas, facturación y calidad de cuentas reales pendientes. No se acredita compatibilidad con todos los equipos/códecs. EXE sin firma comercial; antivirus de los nuevos hashes pendiente.
